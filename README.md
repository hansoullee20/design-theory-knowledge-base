# Design Theory Knowledge Base

A structured, evidence-aware knowledge base covering design theory from foundational principles to expert and research-level topics.

## Objectives

- Document design theories systematically
- Separate empirical evidence, theory, historical doctrine, heuristics, and speculation
- Connect related concepts across design disciplines
- Maintain traceable primary and secondary sources
- Develop a progressive learning path from beginner to expert
- Preserve research history through Git
